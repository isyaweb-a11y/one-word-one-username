## The entry

`main.py` writes the entrant's own make.fun username, one word and
nothing else, to `/output/entry.txt`:

> isyanasarasvati

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
